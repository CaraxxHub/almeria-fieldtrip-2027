# Almería Field Trip 2027 – GeoZentrum Nordbayern (FAU)
Announcement and registration page for the 15–24 March 2027 field trip. Served by GitHub Pages from `main`.
- `index.html` – page (EN/DE); set `CONFIG.ENDPOINT` to the Apps Script web-app URL.
- `backend/Code.gs` – Google Apps Script handler (registrations, 14-place cap, contact form).
- `flyer/build_flyer.py` – rebuilds the A4 flyer and QR code for a given URL.
